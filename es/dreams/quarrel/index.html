Una riña en sueños

Discutes con alguien.

Qué significa

El sueño anuncia disgustos y discusiones acaloradas.

Suele ser una advertencia

Otras versiones de este sueño

  • Para una joven: una ruptura seria.
  • Para una pareja: desacuerdos largos; tened paciencia el uno con el otro.
  • Oír discutir a otros: negocios estancados.
